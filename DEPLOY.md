# Как выложить «Кто я?» в интернет бесплатно

Инструкция для хостинга **Render** (render.com). У него есть бесплатный тариф, поддерживаются WebSocket, и не нужна банковская карта.

Важно знать про бесплатный тариф заранее:
- Если на сайт никто не заходит 15 минут, сервер «засыпает». Первый заход после этого грузится 30–60 секунд, дальше всё работает быстро.
- Когда сервер засыпает или перезапускается, все комнаты стираются: они хранятся в памяти. Посреди игры это не проблема, пока кто-то в ней сидит.

---

## Шаг 0. Запуск у себя (проверка)

Нужен установленный Node.js 18+ (https://nodejs.org).

```powershell
cd C:\Users\DAMUR\Desktop\HedBanz
npm install
npm start
```

Откройте http://localhost:3000. Чтобы проверить игру одному, откройте ссылку на комнату в **другом браузере** или в окне инкогнито: обычные вкладки одного браузера считаются одним игроком.

Друзья в той же Wi-Fi-сети могут зайти по адресу `http://<IP-вашего-компьютера>:3000`. IP можно узнать командой `ipconfig`, строка «IPv4-адрес».

## Шаг 1. Аккаунт на GitHub и репозиторий

Render берёт код из GitHub.

1. Зарегистрируйтесь на https://github.com (если ещё нет аккаунта).
2. Нажмите **«+» → New repository** в правом верхнем углу.
3. Имя: например, `hedbanz`. Видимость: Public или Private, подойдёт любая. Галочки «Add README» и прочие **не ставьте**. Нажмите **Create repository**.

## Шаг 2. Загрузить код

### Вариант А — через браузер (без git)

1. На странице пустого репозитория нажмите ссылку **«uploading an existing file»**.
2. Перетащите туда из папки `HedBanz` следующие файлы и папку:
   - `server.js`
   - `package.json`
   - `package-lock.json`
   - `.gitignore`
   - папку `public` целиком
   
   Папку `node_modules` **не загружайте**: она большая, и Render установит её сам.
3. Нажмите **Commit changes**.

> Если `.gitignore` не видно в проводнике, включите «Вид → Скрытые элементы». Если не получится — ничего страшного, файл не обязателен.

### Вариант Б — через git (если он установлен)

```powershell
cd C:\Users\DAMUR\Desktop\HedBanz
git init
git add .
git commit -m "Кто я? — первая версия"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/hedbanz.git
git push -u origin main
```

## Шаг 3. Создать сервис на Render

1. Зайдите на https://render.com и нажмите **Get Started**. Войдите через **GitHub**: так проще всего подключить репозиторий.
2. В панели нажмите **New + → Web Service**.
3. Выберите **Build and deploy from a Git repository** (если спросят) и найдите репозиторий `hedbanz` → **Connect**.
   Если репозитория нет в списке, нажмите **Configure account** и дайте Render доступ к нему.
4. Заполните поля:

   | Поле | Значение |
   |---|---|
   | Name | `hedbanz` (это будет частью адреса) |
   | Region | Frankfurt (EU Central) — ближе всего к России и СНГ |
   | Branch | `main` |
   | Runtime / Language | `Node` |
   | Build Command | `npm install` |
   | Start Command | `npm start` |
   | Instance Type | **Free** |

   Переменные окружения добавлять не нужно: порт Render задаёт сам, и сервер его подхватывает.
5. Нажмите **Create Web Service** (или **Deploy Web Service**).
6. Подождите 2–3 минуты. Когда в логах появится строка `Кто я? — http://localhost:...` и статус **Live**, сайт готов.

Адрес будет вверху страницы сервиса, примерно такой: `https://hedbanz.onrender.com`. Откройте его, создайте комнату и отправьте друзьям ссылку кнопкой «Скопировать ссылку».

## Шаг 4. Как обновлять

- **Вариант А:** загрузите изменённые файлы в репозиторий так же, через «Add file → Upload files».
- **Вариант Б:** `git add . && git commit -m "..." && git push`.

Render сам заметит изменения и пересоберёт сайт за 1–2 минуты. Активные комнаты при этом сбросятся, поэтому не обновляйте сайт посреди чьей-то игры.

## Если что-то не работает

| Проблема | Что делать |
|---|---|
| Сайт долго открывается | Сервер просыпался, подождите минуту. Можно открыть сайт за пару минут до игры. |
| «Комната не найдена» по старой ссылке | Сервер перезапускался или заснул — создайте новую комнату. |
| Деплой упал с ошибкой | Откройте вкладку **Logs** в Render. Чаще всего в репозиторий не попал `package.json` или папка `public`. |
| Вверху висит «Нет соединения» | Пропал интернет или сервер перезапускается. Страница переподключится сама. |

## Альтернативы Render

Если Render не подойдёт, тот же код без изменений запускается на:
- **Koyeb** (koyeb.com) — тоже есть бесплатный сервис, деплой из GitHub с теми же командами.
- **Railway** (railway.app) — проще в настройке, но бесплатный период ограничен по времени и деньгам на счету.

Везде указываются одни и те же команды: сборка — `npm install`, запуск — `npm start`.
